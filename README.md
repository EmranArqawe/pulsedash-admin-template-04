## 🎯 Project Overview

**PulseDash** is a high-end, multi-page administrative dashboard template engineered entirely from scratch. It serves as a masterclass in modern CSS layout techniques—avoiding heavy frameworks to showcase raw front-end competency, pixel-perfect responsiveness across all viewports, clean architectural design using CSS variables, and comprehensive management workflows across 8 dedicated pages.

---

## 🚀 Key Features

- **Multi-Page Admin System:** Includes 8 fully structured pages: Dashboard, Settings, Profile, Projects, Courses, Friends, Files, and Plans.
- **Fully Responsive UI:** Adaptive layout engineered with CSS Grid, Flexbox, and Media Queries to ensure seamless desktop, tablet, and mobile viewing.
- **Rich Administrative Components:** Features welcome banners, quick draft forms, yearly target progress bars, support ticket statistics, task lists, search rankings, backup managers, and user activity timelines.
- **Custom UI Architecture:** Built with modular utility classes (`framework.css`), custom CSS variables, and Font Awesome icon integration.
- **Semantic HTML Architecture:** Structured with standard HTML5 elements and `Normalize.css` for clean, accessible, and cross-browser compatible markup.

---

## 🛠️ Built With

- **Frontend:** HTML5
- **Styling:** CSS3 (Flexbox, CSS Grid, Custom Variables `:root`, Media Queries)
- **Icons & Fonts:** Font Awesome 6, Google Fonts (*Open Sans*)

---

## 📦 How to Run the Project

1. Clone or download this repository.
2. Ensure all project folders (`css`, `images`) remain in the same root directory.
3. Open `index.html` in any modern web browser to view the dashboard.
